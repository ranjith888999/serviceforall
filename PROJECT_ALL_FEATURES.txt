                       1. APPLICATION OVERVIEW
================================================================================

PROJECT NAME: ServiceForEver

DESCRIPTION:
ServiceForEver is a comprehensive Android application for managing technical
services including CCTV systems, EPABX solutions, biometric systems, and
networking equipment. The app supports multiple user roles (Customer,
Technician, Admin) with distinct features for each.

PRIMARY FUNCTIONS:
  ✓ Browse and purchase products/services
  ✓ Request technician services
  ✓ Manage quotations and bookings
  ✓ Technician network management
  ✓ Order management and tracking
  ✓ Shopping cart and checkout
